# Using Rules

Read [reference/DESIGN.md](reference/DESIGN.md) completely before changing the blog interface.

Use it as the design authority for visual direction, tokens, layout, responsive behavior, themes, interaction, accessibility, and acceptance checks.

Preserve the repository's existing Astro structure and reuse existing styles or components when they satisfy the rules. Make the smallest coherent change that meets the user's request.

Before handoff:

- Verify the affected page at mobile and desktop widths.
- Verify both light and dark themes.
- Check keyboard focus, contrast, overflow, and reduced motion where relevant.
- Report any intentional exception to the design rules.
